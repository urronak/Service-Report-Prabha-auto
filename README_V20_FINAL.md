# PRABHA AUTO V20 Final Fixed

Final maintenance build based on the existing PRABHA AUTO V20 project.

## Included fixes
- Accessories manager: Add / Edit / Delete, quantity, MRP, NDP, GST, supplier, Excel export and PDF/Print.
- Accessories remain separate from spare-parts Current Stock.
- Stock PDF/Print exports Current Stock as quantity only (no ₹ symbol).
- Complete report excludes Stock; Stock can still be selected separately.
- Report picker supports selecting multiple report types.
- Dashboard supplier summary removed so supplier accounts do not occupy the main dashboard; Quick Management remains at the bottom.
- Existing purchase edit/delete and automatic purchase stock handling preserved.
